# Bundled leaf atlas

This directory tracks source recipes only. Run `python3 tools/prepare_samples.py
--texutil ../TexUtil/build/texutil` from the project root. The prepared files are
written under `out/samples/assets/` with this package's relative folder structure.
Do not copy generated maps or atlas manifests back into this source directory.

Generated by TexUtil from `leaves.texutil.json`, using native
`spritesheet` output, seed 42, twelve cells, a 4 × 3 grid and four-pixel padding
inside 256-pixel cells. The recipe is procedural and uses no external photos.
All three PNGs are 1024 × 768 with matching cell placement. Keep them with
`leaves.atlas.json`.

Both `leaves.texutil.json` and its `leaf.texutil.json` source are included here. See [the integration instructions](../../../docs/SPRITESHEETS.md)
to regenerate the package.
