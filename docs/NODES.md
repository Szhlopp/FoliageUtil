# Node reference

Generated by `python3 tools/update_docs.py`. The executable catalog is authoritative.

All angles are degrees; geometry uses meters and right-handed Y-up coordinates.
Every node uses direct parameters beside `op`. Unknown parameters fail validation.
References are node names. Query `foliageutil describe OP` for machine-readable controls.

## boolean

Union, subtract or intersect two oriented closed solids. Preserves source materials, UVs, colors and wind, including cutter properties on new cuts. Recomputes normals; permits cavities and chained cuts.

**Output:** mesh.

| Parameter | Type | Default | Controls |
| --- | --- | --- | --- |
| `crease_angle` | number | `45` | Normal-smoothing threshold in degrees. 180 smooths shading across joins; lower values keep sharp creases. Does not move the surface. Bounds: 0..180. |
| `input` | reference | `required` | Name of an upstream node. Accepts: mesh. |
| `max_input_triangles` | integer | `250000` | Bound total triangles across both operands before preparing Boolean inputs. Bounds: 4..1e+06. |
| `max_shells` | integer | `1024` | Bound total input boundary shells, including cavity surfaces, before the Boolean operation. Bounds: 1..10000. |
| `operation` | string | `"difference"` | Combine input and tool: union, input minus tool, or their common volume. Use solidify first on overlapping shell assemblies. Tool materials label newly exposed cuts. Values: union, difference, intersection. |
| `require_connected` | boolean | `true` | Require at most one positive-volume result body. Closed cavities are allowed. Empty intermediate results are allowed; an empty final output fails ordinary export. |
| `tool` | reference | `required` | Name of an upstream node. Accepts: mesh. |
| `weld_tolerance` | number | `0.0` | World-meter tolerance for joining duplicated seam vertices. Zero uses a scale-dependent float-precision tolerance; not a gap-filling radius. Bounds: 0..0.1. |

## crystal

**Output:** mesh.

| Parameter | Type | Default | Controls |
| --- | --- | --- | --- |
| `height` | number | `1.0` | Full height in meters, from base to tip or table. Bounds: 1e-05..10000. |
| `material` | material | `"leaf"` | Material slot; declare gemstone colors and surface roughness. |
| `radial_jitter` | number | `0.0` | Seeded fractional +/- radius variation per polygon corner, shared by all rings to retain planar prism faces. Bounds: 0..0.35. |
| `radius` | number | `0.20000000298023224` | Circumradius in meters before the profile and jitter. Bounds: 1e-05..10000. |
| `radius_profile` | profile | `[[0, 1], [0.72, 1], [1, 0]]` | Polygon radius over normalized height. Each key makes a ring; only endpoints may be zero (a single apex). Positive endpoints are capped. Nonzero multipliers must be at least 0.0001, and at least one key must be positive. Supply 2..32 keys, strictly increasing from position 0 to 1; bounds apply to multipliers. Bounds: 0..4. |
| `seed` | integer | `omitted` | Optional node seed, independent of the root seed. Node name still identifies its random stream. Bounds: -2.14748e+09..2.14748e+09. |
| `sides` | integer | `6` | Polygon sides per ring. Six suits quartz; eight supports octagonal gems. Bounds: 3..64. |

## solidify

**Output:** mesh.

| --- | --- | --- | --- |

| `input` | reference | `required` | Name of an upstream node. Accepts: mesh. |
