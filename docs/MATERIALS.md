# Material reference

Generated by `python3 tools/update_docs.py` from `foliageutil materials --json`.

These fields belong in each named entry of the root `materials` object.
Unknown fields and invalid bounds fail validation, including unused materials.

Core PBR fields export as glTF materials. Nonzero translucency or subsurface
exports a versioned `extras.foliageutil` object. The Blender preview adapter
applies those optical controls automatically; other viewers need their own adapter.
OBJ/MTL and the solid-color Filament helper do not implement these optics.

Gem transmission, IOR and volume controls use standard glTF extensions.
They are separate from foliage translucency and need a compatible renderer;
see [rocks and crystals](MINERALS.md) for examples and Unity shader limitations.

| Parameter | Type | Default | Controls |
| --- | --- | --- | --- |
| `alpha_cutoff` | number | `0.5` | MASK cutoff. Bounds: 0..1. |
| `alpha_mode` | string | `"OPAQUE"` | glTF coverage mode. Values: OPAQUE, MASK, BLEND. |
| `attenuation_color` | vec3 | `[1, 1, 1]` | Linear RGB light remaining after attenuation_distance through a transmissive volume. Bounds: 0..1. |
| `attenuation_distance` | number | `omitted` | Absorption distance in world meters for volume transmission. Omit for no volume absorption. Requires positive thickness. Bounds: 1e-06..1e+06. |
| `base_color` | color | `[0.35, 0.5, 0.16, 1]` | Linear RGBA, multiplied by vertex color and optional sRGB texture. |
| `base_color_texture` | string | `omitted` | PNG or JPEG, relative to recipe; embedded in GLB. |
| `double_sided` | boolean | `true` | Disable back-face culling for thin leaves/cards. |
| `ior` | number | `1.5` | Dielectric index of refraction, exported with KHR_materials_ior when non-default. E.g. diamond 2.42. Does not model dispersion. Bounds: 1..3. |
| `metallic` | number | `0.0` | PBR metallic multiplier. Bounds: 0..1. |
| `metallic_roughness_texture` | string | `omitted` | Linear packed texture, roughness in G, metallic in B. |
| `normal_texture` | string | `omitted` | Tangent-space OpenGL normal PNG/JPEG. |
| `roughness` | number | `0.800000011920929` | PBR roughness multiplier. Bounds: 0..1. |
| `subsurface` | number | `0.0` | Burley surface diffusion weight in the Blender preview. Saved in GLB foliageutil extras. Bounds: 0..1. |
| `subsurface_radius` | vec3 | `[1, 0.45, 0.25]` | Positive RGB scattering radius ratios, multiplied by subsurface_scale. Bounds: 1e-06..16. |
| `subsurface_scale` | number | `0.001500000013038516` | Surface diffusion scale in meters in the Blender preview. Bounds: 1e-06..1. |
| `thickness` | number | `0.0` | Approximate volume thickness in mesh meters for refractive GLB materials. Positive values require transmission and a closed mesh; ray tracers use the actual surface distance. Bounds: 0..10000. |
| `translucency` | number | `0.0` | Thin-surface diffuse transmission weight, separate from alpha coverage. Saved in GLB foliageutil extras; applied by the Blender preview adapter. Bounds: 0..1. |
| `translucency_color` | vec3 | `[1, 1, 1]` | Linear RGB transmission tint, multiplied by textured base color in the Blender preview. Bounds: 0..1. |
| `transmission` | number | `0.0` | Optical transmission through glass or gems. Exports KHR_materials_transmission; independent of alpha coverage and thin-tissue translucency. Requires a compatible viewer shader. Bounds: 0..1. |
